# NYU Space Talks

History, Politics, Astroculture

## Technology

- Next.js
- React
- TypeScript
- Supabase
- Vercel

## Local development

1. Install dependencies with `npm install`.
2. Copy `.env.example` to `.env.local` and add the Supabase project values.
3. Start the website with `npm run dev`.
4. Open http://localhost:3000.
